# Qradar 제품 범위 (Product Scope)

이 문서는 Qradar 의 **사용자 역할(Role) 과 역할별 기능 명세** 를 정의한다. 기능 단위 task 의 출발점이 되는 "무엇을 만드는가" 의 큰 그림이다.

각 기능의 상세 요구사항/구현은 `docs/tasks/[기능명]/` 의 `spec.md`, `design.md`, `implementation.md`, `test_report.md` 로 관리한다.

---

## 1. 사용자 역할 (Role)

| 역할 | 키 | 설명 |
|------|----|------|
| 슈퍼 관리자 | `admin` | 전체 시스템 관리 |
| 점주 | `owner` | 자신의 매장 관리 |
| 일반 사용자 | `customer` | 주문/결제/탐색 |

### 핵심 플로우 (Customer)

```
앱 실행 → 지도에서 매장 확인 → 검색/필터 → 매장 선택 → 주문
```

---

## 2. 관리자 (Admin) 기능

- 회원 관리 (조회, 정지, 탈퇴 처리)
- 브랜드 등록/수정/삭제
- 메뉴 등록/수정/삭제 (브랜드 단위 마스터 메뉴)
- 매장별 가격 오버라이드 관리
- 전체 매출 조회 (기간별, 매장별, 브랜드별)
- 공지사항 / 배너 관리
- 쿠폰 / 이벤트 관리

---

## 3. 점주 (Owner) 기능

- 메뉴 관리: 관리자 등록 메뉴 기반으로 **품절 처리 / 매장 제외** 가능
- 매장 운영시간 등록 (운영시간 외 주문 자동 차단)
- 매출 조회: 시간대별, 일별, 월별, 연별, 카드사별, POS 주문 vs 앱 주문 vs 오프라인 구분
- 주문 접수/거절/완료 처리
- 매장 정보 수정 (주소, 전화번호, 사진)

---

## 4. 고객 (Customer) 기능

- 회원가입 / 로그인: 카카오, 네이버, 구글, 이메일 인증
- 지도 기반 매장 탐색 + 필터 (거리, 브랜드, 현재 영업중 등)
- 장바구니 (카트): 매장별 독립 카트
- 주문: 사이렌오더(픽업), 배달 선택
- 결제 수단: 토스페이먼츠, 카카오페이, 네이버페이, 신용/체크카드
- 주문 상태 알림: 접수 → 제조중 → 픽업 완료 (FCM 푸시)
- 적립 포인트 시스템 (Qoin)
- 선물하기: 기프트카드, 쿠폰, 음료 선물
- 매장 후기 작성 / 조회 / 평점 (1~5점)
- 주문 내역 조회 (Log)

---

## 5. 추천 추가 기능 (기획 고려사항)

- **웨이팅 기능**: 매장 혼잡도 표시 및 원격 대기 등록
- **멤버십 등급**: 브론즈/실버/골드 등 등급별 혜택 차등
- **직원(바리스타) 앱**: 주문 접수 처리 전용 별도 화면
- **정기 구독**: 월정액 음료 구독권
- **알레르기/영양 정보**: 메뉴별 성분 표시
- **주문 예약**: 원하는 시간에 픽업 예약 주문

---

## 6. Qradar 고유 용어

화면명, 문구, 코드, 문서에서 가능한 한 일관되게 사용한다. 코드 가독성을 해치는 경우에는 도메인 명명 규칙을 우선한다.

| 일반 용어 | Qradar 용어 | 설명 |
|-----------|------------|------|
| 앱 화폐 | **Qoin** | Coin 의 C 를 Q 로 |
| 사용자 | **Qrator** | Curator 의 C 를 Q 로. 품질 선별자 |
| 주문 내역 | **Log** | 선별자가 기록을 남긴다는 의미 |
